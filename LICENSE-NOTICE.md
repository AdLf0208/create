## This port

- **Licence:** **MIT** (the code grant), with the complete source in this repository.
- **What it is:** a clean-room Rust rewrite of Create's interop surface — one Creative Motor
  block whose block entity publishes `Speed`, `Capacity`, `Stress` and `NetworkStatus` for
  dependent add-ons to read from a neighbouring block. No network solver, no cross-mod Rust
  API; connected propagation and stress accounting are the next slice. The pure rules live in
  `src/runtime.rs`.
- **Assets:** every texture, model, blockstate, item definition, language entry, data file and
  the monogram icon is **generated by this port** with `tools/gen_assets.py`, from its own
  palette and shapes. The upstream art is never read or copied. `tools/check_provenance.py
  --check` hashes every jar entry against every candidate and packaged file and fails on any
  match; the measured result is **zero jar-derived bytes**. `PROVENANCE.md` is its report.
